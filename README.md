# Flying Chess (Aeroplane Chess)

Implementations of flying chess (AKA aeroplane chess).

## 📱 Mobile app (React Native + Expo) — playable now

A complete, playable **iOS** version in **[`mobile/`](./mobile)**: 2‑player team
mode (Yellow + Green vs Red + Blue), pass‑and‑play on one device.

**Test it on your iPhone with no Mac or Xcode** — install the free *Expo Go* app,
then run the dev server and scan the QR code:

```bash
cd mobile
npm install
npx expo start
```

See **[`mobile/README.md`](./mobile/README.md)** for full instructions, rules, and
project layout.
